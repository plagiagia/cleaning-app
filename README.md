# Sparkle Clean

A mobile-first cleaning service booking app — inspired by platforms like Clean Whale.

## Features (draft)

- Horizontal date picker (next 14 days)
- Available time slots per date
- Service catalogue with upfront pricing
- Sticky bottom bar with booking summary

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your phone or use browser dev tools in mobile view.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Deploy

Ready for [Vercel](https://vercel.com) — connect the GitHub repo and deploy.
